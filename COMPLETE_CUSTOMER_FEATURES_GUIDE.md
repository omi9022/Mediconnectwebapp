   - CVV code
   - Cardholder name
   - Secure payment

2. **UPI** 📱
   - Pay via UPI apps
   - GPay, PhonePe, etc.
   - Instant payment

3. **Net Banking** 🏦
   - Direct bank transfer
   - All major banks
   - Secure gateway

4. **Wallet** 💰
   - Paytm
   - Amazon Pay
   - PhonePe Wallet
   - Quick payment

5. **Cash on Delivery** 📦
   - Pay on delivery
   - No advance payment
   - Safe & convenient

```

2. Review cart
3. Click "Place Order"
4. Select payment method
5. Enter payment details (if card)
6. Click "Confirm Payment"
7. Order placed successfully!
8. Receive Order ID
```
