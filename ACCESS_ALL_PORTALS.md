## 🚀 **HOW TO ACCESS:**

### **Step 1: Start the Servers**

**Windows Users:**
```bash
start-servers.bat
```

**Mac/Linux Users:**
```bash
chmod +x start-servers.sh
./start-servers.sh
```

**Manual Method (Any OS):**
```bash
# Terminal 1 - Backend
cd backend
python main.py

# Terminal 2 - Frontend (new terminal)
npm run dev
```

### **Step 2: Open Your Browser**
```
http://localhost:5173
```

### **Step 3: Select Your Portal**

You'll see **3 TABS** at the top of the login page:

```
┌─────────────────────────────────────────┐
│  [Hospital]  [Support]  [Customer]      │
│                                          │
│  Click the tab for the portal you want  │
└─────────────────────────────────────────┘
```

### **Step 4: Enter Credentials**

Click your desired tab, then enter:
- **Username** (from table above)
- **Password** (from table above)

### **Step 5: Click Login**

You're in! 🎉

✓ Verify correct tab was selected
