## 📱 USER FLOWS

### Complete Shopping Flow:
```
1. Login as customer
2. Navigate to "Stock Search"
3. Search for medicine (e.g., "Paracetamol")
4. Filter by category (e.g., "Pharma")
5. Review product details
6. Click "Add to Cart"
7. Cart badge updates
8. Click cart icon
9. Review cart items
10. Update quantities if needed
11. Click "Place Order"
12. Select payment method
13. Enter payment details
14. Click "Confirm Payment"
15. Order placed successfully!
16. Receive Order ID
17. Track in "Logistics"
```
